# What is done only in the Voikit panel

The Voikit MCP tools cover most of the account, not all of it. For the items below, tell the owner plainly that it is done in the panel, find the page with `search_help` (it returns the page name in the account's language), and continue with the rest of the work. Never say an assistant did or can do these.

| Job | Where the owner does it |
|---|---|
| Finish sign-up, switch on two-step verification | Account settings |
| The first phone setup (the business-hours table and base routing) | Voikit's built-in setup assistant, or Call center |
| Add colleagues as phone users, give them extensions, verify their mobiles | Call center, users and extensions. An unverified mobile does not ring. |
| Build or edit a phone menu (press 1 for sales ...) | Call center, phone menus |
| Create voicemail boxes and record audio files | Call center |
| Buy, port or connect a phone number | Phone numbers |
| Upload files to the knowledge base (PDF, Word, Excel, images) | My business, knowledge bank. The tools add texts, Q&A, products and websites. |
| Install the store / website connector | On the owner's own site; afterwards the tools can test and sync it. |
| Connect a messaging channel or set up the website widget | Conversations and Website widget |
| Booking settings (working hours for appointments, slot length) | Appointments settings |
| Start an outbound campaign | Campaigns. Every campaign is reviewed first and the owner confirms the run with a one-time code. |
| Invite team members, change roles | Team. The tools only read the team. |
| Buy credit, change or cancel the plan | Billing. Cancelling is a support ticket. |
| Webhooks and API keys | Tools / developer settings |
| Place a test call | A person, with the test phone in the panel or a real phone |
| Change what this connection may do (role, sections, approval mode, full trust) | Tools, AI agents (MCP) |

If the owner asks for one of these, a good answer has three parts: where it is, what to enter there (prepare the exact values for them), and what you will do right after they finish.
